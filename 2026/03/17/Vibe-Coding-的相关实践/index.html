Vibe Coding 的相关实践

本文最后更新于：2026年3月24日 晚上

前言

最近在研究量化（还只停留在跑模型因子选股的阶段），在训练出一个还算凑合的模型后。想基于这个模型展示一个基础的web界面展示股票，回测等情况。yysy，现在的ai工具如果不是订阅制，token烧的飞快。

我个人的技术背景只有后端开发的一些相关经验（主要语言是Java），没有前端开发的经验。目前使用的工具是Codex（咸鱼9.9一个月的太香了），再此基础上完成一个基础的ai选股模型的开发和一个应用demo。

需求分析

做软件搞明白需求还是还是第一步，前期的训练模型已经在ai的帮助下基本完成（效果怎么样另说），总结下来有以下几点

序号 需求 级别
1 每日定时任务更新日线数据 P0
2 每日使用新数据进行预测，展示预测signal，并展示股票的socre排序 P0
3 多模型模型选择切换 P1
3 回测图标展示 P1
4 接入agent尝试自动生成因子 P2
5 最为重要的训练模型部分 P1
